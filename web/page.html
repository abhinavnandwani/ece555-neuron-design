Carry-save count architecture

Every product and the bias is −1, 0 or +1, stored as a nonzero bit y0 and a negative bit y1, so its value is y0 − 2·y1. That makes the sum

  • sum = (#nonzero) − 2·(#negative)
  • Two full adders in parallel count them: #nonzero = nz.sum + 2·nz.carry, #negative = neg.sum + 2·neg.carry
  • out[1] = nz.carry · !neg.sum · !neg.carry (one NOR3)
  • out[0] = nz.sum · !neg.carry · (nz.carry + !neg.sum) (one AOI211)

This replaces both ripple adders and the ReLU mux with one full-adder delay plus one gate. It still contains a multiplier, adders and the activation, but check with your TA that a restructured datapath is allowed (slide 14 calls its block list an example).
